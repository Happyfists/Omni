# omni

All-in-one Ashita v4 addon for CatsEyeXI, by Happyfists.

A small bar along the top of the screen (job, XP/LP, wallet, buffs, target with TH and distance) and a drop-down panel of tabs: Happy Healer, Abyssea procs and NM pops, Quests, Multisend, Damage, Character, Currency, Dailies, Codex, Sky, Sea, Ventures, Sparks, Options and Treasure Hunter. It also draws spell animations on the field (fireballs, lightning, rocks, cures...) and party job pictures.

## Install

Copy the `omni` folder into your addons folder:

- VanaCore: `catseyexi-client\Vanacore\addons\ashita\omni\` then `/addon load omni ashita`
- Ashita: `catseyexi-client\Ashita\addons\omni\` then `/addon load omni`

See **README.txt** for everything it does, commands and settings.
